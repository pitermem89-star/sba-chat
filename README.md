# Мини-чат поверх приложений (Android)

Плавающий чат: кружок 💬 висит поверх игр и других приложений, по нажатию раскрывается окно чата. Фильтра слов нет.

## Как это получить

1. Загрузи все файлы этого проекта в репозиторий на GitHub (ветка `main`).
2. Открой вкладку **Actions** → дождись зелёной галочки у **Build APK**.
3. Открой **Releases** → скачай `app-debug.apk` → установи (разреши установку из неизвестных источников).

## Как настроить чат

1. Зайди на console.firebase.google.com → создай проект → **Build → Realtime Database → Create database**.
2. Скопируй ссылку вида `https://…firebaseio.com` и вставь в приложении.
3. Во вкладке **Rules** вставь правила (в приложении есть кнопка «Скопировать правила для Firebase») и нажми **Publish**.
4. Придумай ник и название комнаты (у друзей должна быть та же комната и та же ссылка на базу).
5. Нажми «Разрешить показ поверх приложений», потом «Запустить чат».

## Как менять внешний вид

Все цвета, размеры и надписи лежат в одном файле: `app/src/main/java/com/minichat/app/Style.kt`.
