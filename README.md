# Мини-чат поверх приложений (Android)

Плавающий чат: кружок 💬 висит поверх игр и других приложений, по нажатию раскрывается окно чата. Фильтра слов нет.
Регистрация и настройка сервера не нужны: используется бесплатный сервер ntfy.sh, он уже встроен в приложение.

## Как получить приложение

1. Открой вкладку **Actions** → дождись зелёной галочки у **Build APK**.
2. Открой **Releases** → скачай `app-debug.apk` → установи (разреши установку из неизвестных источников).

## Как пользоваться

1. Впиши ник (обязательно, потом его можно сменить кнопкой ✎ в окне чата).
2. Создай комнату или войди в чужую:
   - **открытая**: только название; войдёт любой, кто его знает;
   - **закрытая**: название и пароль; без пароля комнату не найти.
3. Нажми «Разрешить показ поверх приложений», потом «Запустить чат».
4. В окне чата поверх игры кнопка ⇄ открывает список комнат: можно переключаться, создавать новые и входить в чужие.

Чтобы друзья попали в твою комнату, скажи им название (и пароль, если она закрытая).

## Как менять внешний вид

Все цвета, размеры и надписи лежат в одном файле: `app/src/main/java/com/minichat/app/Style.kt`.
